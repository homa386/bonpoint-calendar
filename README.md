# bonpoint-calendar

営業日カレンダー画像（1080×1350 PNG）の作成ツール（`index.html`）。

## 使い方
1. `index.html` をブラウザで開く（GitHub Pages で公開するとスマホからも使えます）
2. 来月のカレンダーが表示され、定休日（月・火）には最初から「休」が付いています
3. 臨時休業や営業する日をタップして「休」を付け外し
4. 「画像を保存」で書き出し

- 日曜・祝日（振替休日・国民の休日を含む）は赤、土曜は青で自動表示されます
- 定休日の曜日と営業時間は「設定」から変更できます（営業時間は1行ごとに「曜日 時間」）
- 設定と各月の変更は、その端末のブラウザに保存されます
